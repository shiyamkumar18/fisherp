# FisherP 2-Minute Demo Script

## 1. Intro (10 sec)
“This app helps you manage your fish business easily.”

## 2. Show Purchase (20 sec)
- Go to the Purchase page.
- Add new fish stock (show the add form, submit, and confirm it appears in inventory).

## 3. Show Inventory (20 sec)
- Go to Inventory.
- Point out the updated stock and how it’s always current.

## 4. Show Order (20 sec)
- Go to Orders.
- Create a new order (sell fish), show how it’s tracked.

## 5. Show Payment (20 sec)
- Go to Payments.
- Show payment tracking: who owes, what’s paid.

## 6. Show Dashboard (20 sec)
- Go to Dashboard.
- Show the business overview: sales, stock, money—all in one place.

---

**Tips:**
- Don’t show settings, admin, or technical features.
- Move fast, focus on benefits, not features.
- End with: “What do you think? What’s missing for you?”

---

**For Founders:**
- Use this script for every real user demo.
- Capture feedback after each demo.
- Iterate based on real user pain, not assumptions.
